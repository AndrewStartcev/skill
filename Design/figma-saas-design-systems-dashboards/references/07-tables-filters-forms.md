# 07. Data tables, фильтры, CRUD и массовые операции

## Таблицы
Для каждой таблицы зафиксируй: ключ записи, главную колонку, тип данных колонок, сортировку по умолчанию, доступные действия, плотность строк, ширины, pagination/virtualization на уровне UX, поведение при пустом результате. В Figma показывай реалистичную разную длину строк и значений.

- Текст выравнивай по началу, числовые суммы — по разрядам/правому краю.
- Идентификатор и имя должны оставаться узнаваемыми даже при горизонтальной прокрутке.
- Статусы выражай текстом + визуальным кодом; цвет один не достаточен.
- Sort: показывай текущую колонку, направление и что происходит с null.
- Выбор строк: checkbox заголовка должен различать «текущая страница» и «вся выборка».
- Row action vs table toolbar: действия над одной записью контекстно, над несколькими — в явной bulk-панели.
- Для редактирования выбери inline/modal/detail согласно сложности, цене ошибки и контексту.

## Фильтрация
Формат спецификации: название фильтра → область → тип → default → допустимые значения → взаимосвязи → clear/reset → сохранение в URL/виде (если это часть продукта). Отличай поиск, фильтры и сортировку.

Фильтры должны явно показывать выбранные условия: chips, summary, счётчик результатов, reset. После фильтрации — empty result с понятной возможностью сброса.

## Массовые операции
Проектируй:
1. Выбрано **N** элементов; что входит в N: страница/вся выборка.
2. Какие действия доступны согласно разрешениям.
3. Какие записи будут пропущены и почему (mixed permissions).
4. Предупреждение перед irreversible action.
5. Состояния выполнения, частичного успеха/ошибки, итоговый feedback.
6. Отмена/undo при фактической поддержке сценария.

## Формы
- Группируй поля по логической задаче; основной action обозначай явно.
- Labels всегда есть, placeholders не заменяют labels.
- Required/optional понятны заранее; errors локальны и связаны с полем.
- При длительной форме нужны сохранение черновика/unsaved changes, если предусмотрены.
- Успех — конкретный результат (что создано, где посмотреть), а не просто зелёный toast.
- Для денег/дат/телефонов учитывай локаль и формат.

## Обязательные состояния для Figma
`default / loading / empty-dataset / empty-filter-result / error / partial-data / no-permission / selected / bulk-progress` — релевантные сочетания, а не одинаковая универсальная заглушка.
