# Проверка скилла

Необходим только Python 3 (стандартная библиотека). Скрипт не подключается к Figma, GitHub, API и сети. Он проверяет **файлы документации**, а не качество Figma-дизайна.

Из корня нового скилла:

```bash
python3 scripts/validate_skill.py
```

Проверяются:
- Наличие `SKILL.md` и каталогов `references/`, `assets/`, `scripts/`.
- YAML frontmatter с `name` и `description` (простая структурная проверка).
- Относительные Markdown-ссылки на файлы и директории.
- Валидность `assets/tokens-example.json`.
- Непустые CSV-шаблоны и равная длина строк.
- Случайные GitHub-токены и фрагменты приватных ключей по базовым шаблонам.

Скрипт не заменяет проверку безопасности, QA, лицензий или авторскую экспертизу. При ошибке завершает работу с кодом 1.
