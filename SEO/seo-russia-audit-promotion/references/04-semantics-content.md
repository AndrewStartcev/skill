# Семантика, структура и контент

## 1. Сбор спроса
Собери seed-запросы из услуг/товаров, CRM и терминов клиентов; расширь подсказками, Wordstat, Вебмастером, GSC, внутренним поиском, конкурентами и сезонностью. Раздели брендовую и небрендовую семантику; информационный, коммерческий, навигационный, локальный и смешанный интент. Указывай регион, устройство, период и источник частотности. Не суммируй некорректно частоты разных типов соответствия.

## 2. Кластеризация
Группируй по потребности пользователя и типу результата в SERP, а не только по похожим словам. Для каждого кластера укажи: основную тему, уточнения, географию, целевой URL/шаблон, бизнес-ценность, приоритет, текущую видимость, план контента. Используй [CSV-шаблон](../assets/keyword-map-template.csv).

**Правило посадочной:** одна сильная страница может покрывать несколько близких запросов; не создавай отдельную страницу под каждую словоформу. Отдельная страница оправдана, если интент, предложение и ожидаемый результат действительно различаются.

## 3. Карта сайта
Сверь структуру с потребностями: главная → категории/услуги → подкатегории/листинги → карточки/детали; отдельно информационный хаб и страницы бренда/контактов. Проверь наличие хлебных крошек, контекстных ссылок, фильтров и доступности важных страниц в 2–4 осмысленных перехода (не жёсткий ранжирующий норматив).

## 4. Аудит страниц
- Интент и полнота ответа; соответствие цены, региона, ассортимента, наличия, услуги и CTA.
- Уникальный полезный контент: характеристики, сравнения, фото, ограничения, кейсы, ответы на вопросы, условия и доказательства компетенции.
- `title` и H1 описывают страницу без переспама; description помогает сформировать сниппет, но поисковик может заменить его.
- Нет каннибализации: несколько URL конкурируют за один интент без ясного распределения. Диагностируй по показам, URL и SERP, а не только по одинаковому ключу.
- Для устаревших страниц: обновить, объединить с эквивалентной и перенаправить, оставить как архив или удалить с корректным статусом — решение по спросу и ссылкам.

## 5. Контент-план
Для каждой темы: аудитория, интент, ключевые вопросы, структура H2/H3, факты и источники, эксперт-ревью, медиа, внутренние ссылки, CTA, дата пересмотра, критерии качества. Не задавай универсальную длину текста, плотность ключей или обязательное число заголовков. AI-контент оценивай по фактической полезности, оригинальности, точности и ответственности, а не по способу генерации.

## 6. Контент с высокой ответственностью
Медицина, финансы, право и безопасность: проверка квалифицированным специалистом, дата и авторство, ссылки на первоисточники, прозрачные ограничения, отсутствие недоказанных обещаний. Не подменяй юридическую проверку SEO-советами; соблюдение российских требований к рекламе, персональным данным и медицинской информации проверяет профильный специалист.

## 7. Анализ конкурентов
Выбирай конкурентов по выдаче для конкретных кластеров и городов, а не только бизнес-конкурентов. Сравни: типы посадочных, полноту ассортимента, контент, UX, доверие, локальные карточки, внутреннюю архитектуру, сниппеты. Отделяй корреляцию от причинности. Не копируй чужие тексты и структуру механически.

## 8. Приёмка
Готовая карта запросов не содержит дублирующих посадочных для одного интента без объяснения, у каждой приоритетной страницы есть конкретный бриф и KPI; структура доступна пользователю и роботу, а опубликованный контент соответствует бизнес-фактам.
