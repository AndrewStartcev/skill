# Безопасный первичный SEO-crawl

`site_audit.py` — инструмент без внешних Python-зависимостей. Он проверяет HTTP/HTML, robots, sitemap, базовые SEO-метаданные, внутренние ссылки и выдаёт JSON/CSV/Markdown. Это **не** полноценный аналог браузерного краулера, Яндекс Вебмастера, GSC или анализа реальной индексации.

## Требования и запуск
Python 3.11+ и сетевой доступ к **своему или согласованному** публичному сайту.

```bash
python3 scripts/site_audit.py https://example.com/ --max-pages 50 --delay 0.5 --output ./seo-audit-output
python3 -m unittest discover -s scripts -p 'test_*.py' -v
```

Запускать из каталога скилла. Скрипт по умолчанию:
- уважает `robots.txt` и прекращает работу, если не может безопасно определить правила;
- ограничен одним hostname, публичными IP, `http/https`, 50 страницами, задержкой 0.5 с и ограничением размера ответа;
- не входит в аккаунты, не отправляет формы, не изменяет сайт и не следует внешним редиректам;
- собирает ссылки из sitemap (с лимитом) и HTML; не исполняет JavaScript;
- записывает `report.json`, `issues.csv` и `summary.md` локально.

`--allow-private` разрешён **только** для собственной согласованной staging-среды, если требуется проверка приватного IP; не использовать против чужих адресов. Обход robots не предусмотрен.

## Интерпретация
«Нет title», «404 в sitemap» и «noindex в sitemap» — технические сигналы. Отсутствие `meta description`, несколько H1, `alt` или `canonical` не всегда ошибка: нужна ручная оценка назначения страницы. Скрипт не измеряет позиции, трафик, индексацию, JS-render, CWV, полноту Schema.org и фактическую полезность контента.

Выходные файлы могут содержать URL с параметрами. Проверь их на токены и персональные данные перед публикацией; не коммить отчёты реальных клиентов. При больших сайтах используй выборку по типам страниц и профессиональный краулер с согласованной скоростью.
