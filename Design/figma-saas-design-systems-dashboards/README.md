# Figma: дизайн-системы, SaaS и дашборды

Скилл для **проектирования интерфейсов в Figma**, не программирования SaaS-приложений и не Sass/SCSS.

## С чего начать
1. Открой [SKILL.md](SKILL.md) — короткий обязательный процесс.
2. Под выбранный тип задачи читай только релевантные [references](references/).
3. Заполни шаблоны из [assets](assets/).
4. Проверь структуру и относительные ссылки командой из [scripts/README.md](scripts/README.md).

## Что покрывает
- B2B SaaS, CRM, ERP, аналитические и операционные рабочие кабинеты.
- Figma foundations, Variables, collections/modes, tokens, Auto Layout, components и variants.
- Data tables, фильтры, bulk-операции, карточки сущностей, permission states.
- Дашборды, KPI, графики, UX-сценарии и прототипы.
- Design QA, WCAG-ориентированные макеты, локализацию и handoff.

## Что не входит
Реализация на React/Next.js, Sass/SCSS, API, базы данных, эксплуатация SaaS, SEO-продвижение публичных сайтов и импорт чужих платных UI-kit без лицензий. При необходимости используй соответствующий отдельный скилл.

**Источники:** [references/13-sources.md](references/13-sources.md). Документы — универсальные шаблоны, без клиентских данных.
