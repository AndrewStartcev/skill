# Handoff / приемка — чек-лист

## Дизайн
- [ ] Актуальные фреймы помечены Ready for dev, старые версии в архиве.
- [ ] Токены/стили/компоненты и их соответствие frontend определены.
- [ ] Есть desktop/mobile, промежуточная ширина и правила responsive.
- [ ] Для всех важных компонентов есть состояния и поведение.
- [ ] Изображения, иконки и шрифты имеют понятные лицензии и параметры экспорта.

## Контент и SEO
- [ ] Title/description/H1 и URL указаны для ключевых страниц.
- [ ] SEO-кластеры и интенты согласованы; тексты утверждены владельцем фактов.
- [ ] Важный контент и внутренние ссылки доступны в HTML.
- [ ] Canonical, robots, sitemap, breadcrumbs, structured data документированы.
- [ ] При редизайне проверены URL-map, 301, 404/410, сохранность контента.
- [ ] Нет выдуманных цен, отзывов, гарантий и лицензий.

## UX и доступность
- [ ] CTA и навигация однозначны, формы имеют labels и состояния ошибок.
- [ ] Контраст, фокус, клавиатура, reflow проверяются на реализации.
- [ ] Пустые/длинные данные не ломают интерфейс.
- [ ] Подготовлены тестовые сценарии основных путей.

## Техническое и измерение
- [ ] Компоненты/шаблоны CMS и источники данных определены.
- [ ] Breakpoints, sticky, overflow, z-index, animation, lazy loading описаны.
- [ ] События и цели аналитики перечислены и будут проверены.
- [ ] Предрелизный crawl, performance, a11y и регрессия запланированы.
- [ ] Есть ответственный за релиз, rollback и мониторинг.
