# Проверка макета, контента, SEO и результата

## Матрица QA
| Уровень | Что проверить | Чем подтвердить |
| --- | --- | --- |
| Discovery | цели, аудитория, baseline, подтвержденные факты | бриф и ссылки на данные |
| IA | все ключевые интенты имеют релевантные страницы | sitemap, контент-матрица |
| UX | главные задачи достижимы, понятные CTA и формы | прототип + наблюдения тестов |
| Visual | ритм, сетка, типографика, реальный контент | ревью Figma на 3+ ширинах |
| Components | Auto Layout, variables, variants, states | инспекция Figma |
| Accessibility | контраст, фокус, labels, keyboard, reflow | ручная проверка HTML + инструменты |
| SEO | URL, title, description, H1, canonical, robots, links, HTML | crawl + Search Console/Вебмастер |
| Performance | LCP, INP, CLS и причины отклонений | CrUX/field data + lab |
| Analytics | цели, события, воронки, сегменты | тестовые события и отчеты |
| Redesign | URL-map, 301, 404, sitemap, rollback | старый/новый crawl и лог |
| Content | факты, экспертная проверка, лицензии, тон | согласованная матрица |

## Проверка в Figma
- Варианты ширины: условно 360/390, 768, 1024, 1440 — примеры тестовых точек, не нормативные breakpoints.
- Тестовые данные: пустой список, очень длинное название, цена с несколькими разрядами, много FAQ, ошибка формы.
- Проверка сценариев: меню, карточка → заявка, фильтры → результаты, поиск → пусто, отправка → подтверждение.
- Контентная QA: заголовки/CTA/тексты ошибок/подписи/alt-план и SEO-метаданные.
- Визуальный и контентный аудит оформляй как issues с приоритетом, владельцем и критерием приемки.

## Проверка в браузере
- Клавиатура Tab/Shift+Tab/Enter/Space/Escape, фокус в модальных окнах, screen reader на основных сценариях.
- Zoom/reflow, mobile Safari/Chrome, медленная сеть, отсутствие/ошибки JS по релевантности.
- HTML-source и rendered DOM, HTTP-коды, редиректы, канонические URL, индексация и sitemap.
- Формы, ошибки, события аналитики, согласия на обработку данных, безопасность и отсутствие утечек.
- Проверяй структурированные данные инструментами поисковых систем и соответствие видимому контенту.

## KPI
**Бизнес:** целевые лиды/продажи, CR, доход, стоимость лида по доступным данным.

**UX:** task success, time-on-task, ошибки, завершение форм, доля успешных поисков по сайту; собирай измерения только при наличии данных.

**SEO:** органические целевые конверсии, клики/показы/CTR, видимость по интентам и регионам, доля индексируемых важных URL, 404, каннибализация.

**Техническое:** CWV на 75-м перцентиле по мобильным/desktop; ошибки JS, доступность, время до интерактивного сценария.

## Приоритеты
- **P0:** критичный путь недоступен, массовый noindex/404, потеря оплаты/заявок, грубая утечка данных.
- **P1:** важная страница потеряла контент/URL без решения, форма не работает на части устройств, недоступное основное управление.
- **P2:** заметные проблемы читаемости, семантики, визуального переполнения, отдельные проблемы скорости.
- **P3:** декоративные и второстепенные улучшения.

## Измерение эффекта
Фиксируй baseline до изменений, дату релиза, сезонность, кампании, изменения ассортимента/цен. Сравнивай одинаковые сегменты, не выдавай простой рост/падение за причинный эффект дизайна. Для A/B — заранее формулируй гипотезу, primary metric, guardrails и достаточную длительность; не останавливай тест после первого удачного дня.

## Definition of Done
Согласованы бриф и контент; макеты/компоненты переданы; критические QA закрыты; URL-map проверен; аналитика работает; владелец сайта знает, что мониторить после релиза.
