## Пример: страница услуги мастерской мебели

**Задача:** посетитель ищет ремонт деревянной мебели, хочет понять состав работ, стоимость и способ оставить заявку.

**Интент:** коммерческий + локальный. **Регион:** условный «Город N». **URL:** https://example.com/services/wood-furniture-repair/.

### Черновая карта страницы
| Блок | Зачем | Текст для макета | Проверка |
| --- | --- | --- | --- |
| Hero / H1 | подтвердить интент | Ремонт деревянной мебели | услуги и география подтверждаются |
| Lead | объяснить процесс | Опиши, что нужно восстановить, и приложи фотографии — обсудим возможные работы. | проверить фактический процесс |
| CTA | запустить действие | Отправить фото на оценку | согласовать канал/согласия |
| Виды работ | помочь с выбором | Восстановление покрытия / ремонт соединений / замена фурнитуры | подтвердить перечень |
| Стоимость | снять возражение | Стоимость зависит от состояния мебели и объема работ. | согласовать формулировку |
| Этапы | снизить неопределенность | Заявка → уточнение деталей → согласование работ → выполнение | подтвердить этапы |
| Примеры | доказательства | До/после с подписью о выполненных работах | реальные фото и разрешения |
| FAQ | закрыть вопросы | Можно ли оценить работу по фотографии? | ответ только после согласования |
| Контакты | завершить путь | Форма, способы связи, график | реальные данные |

### Пример SEO-метаполей (только после проверки фактов)
- **Title:** Ремонт деревянной мебели — виды работ и заявка | Мастерская Пример
- **Description:** Узнай, какие работы по ремонту деревянной мебели доступны. Опиши задачу и отправь фотографии для обсуждения вариантов восстановления.
- **H1:** Ремонт деревянной мебели
- **Основной запрос:** ремонт деревянной мебели
- **Вторичные формулировки:** реставрация деревянной мебели, восстановление покрытия — включать только если услуги действительно оказываются и интент совпадает.
- **CTA:** Отправить фото на оценку
- **Alt-план:** «Поврежденная поверхность деревянного стола до ремонта» для соответствующего реального изображения; декоративные иллюстрации без информативного alt.

Не обещай «бесплатно», «за 1 день», «лучшие мастера», пока это не подтверждено.

### Пример структуры Figma
~~~text
05 Screens
└── Service / Desktop / Default
    ├── Header (instance)
    ├── Main (auto layout: vertical)
    │   ├── Hero (auto layout: horizontal)
    │   │   ├── Content (H1, lead, CTA)
    │   │   └── Media (aspect-ratio + alt annotation)
    │   ├── WorkTypes (section + card instances)
    │   ├── PricingExplanation (section)
    │   ├── Process (step instances)
    │   ├── Examples (cards + real media)
    │   ├── FAQ (accordion instances)
    │   └── LeadForm (labels + states)
    └── Footer (instance)
~~~

Создай «Service / Mobile / Default» из той же системы, проверь длинный H1, отсутствие фото и ошибки формы. Не просто уменьши desktop до 390px.

## Пример редизайна
Старая страница https://example.com/remont-mebeli/ приносит органический трафик; новый макет предлагает /services/wood-furniture-repair/.

**Правильная последовательность:** измерить baseline → проверить интент и содержание → выбрать keep или 301 → обновить ссылки → протестировать на staging → запустить → мониторить.

**Неправильно:** удалить старую страницу и перенаправить ее на главную, потому что «в меню стало красивее».

## Пример краткого отчета по Figma
- **P1 / Service-Mobile / LeadForm:** при открытии клавиатуры sticky CTA перекрывает кнопку отправки. Проверка: мобильный viewport и ввод в последнее поле. Исправление: изменить поведение sticky, обеспечить доступность кнопки и фокуса.
- **P1 / Service-Desktop / Hero:** макет использует неподтвержденное «Гарантия результата 100%». Исправление: убрать или заменить на согласованную формулировку.
- **P2 / Components / ServiceCard:** карточка обрезает заголовки более 45 символов. Исправление: Auto Layout + высота по содержимому + тест длинных названий.
- **P2 / SEO:** новая версия не содержит описания видов работ, присутствовавшего на индексируемой старой странице. Исправление: оценить интент/органику и вернуть полезный контент или согласовать замену.
